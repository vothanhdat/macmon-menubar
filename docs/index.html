For Apple Silicon Macs

See what your Mac is doing, and what it did all week.

A tiny menu bar monitor: CPU, GPU, RAM, power, battery, temperature, fans and disk. It keeps 30 days of history, adds up what each app used over 90 days, and shows the same charts in a terminal over SSH.

More than the numbers right now

Most monitors show this second. MacMon Indicator also answers the questions you have afterwards.

What used my battery this week?

Process History adds up CPU time, CPU energy, memory and disk for every app and program, over today, 24 hours, or 7, 30 or 90 days.

How is the Mac mini in the closet?

SSH in and run macmon-indicator: the same charts, top processes and process history, drawn in the terminal.

Does the monitor itself cost much?

About half a percent of one core and 22 to 31 MB of memory with the menu closed, measured and explained below.

A menu bar item you can read at a glance

Two lines with an icon per value, or one line. Pick up to six metrics and adjust text size, spacing and opacity; the bar updates live while you drag.

  • Values turn orange or red past limits you set.
  • Fixed column widths, so the bar never jitters.
  • Starts at login, no Dock icon, stays out of the way.

It follows light and dark mode, with the same glass look as your other menus.

History from one minute to thirty days

A native macOS menu with charts for 1m, 5m, 1h, 24h, 7d and 30d. The solid bar is the average and the faint bar is the peak, so short spikes stay visible.

  • Hover to read the value at any moment; click a chart to see it alone at full width.
  • Top processes by CPU, CPU time, RAM, disk and kernel time. Click a column for its top ten.
  • Disk operations per second: many small reads and writes can slow a Mac while the MB/s stay low.
  • Keep it on screen in a resizable dashboard window.
  • Sleep and time the app wasn't running show as gaps, not as zeros.

What each program used, added up

Every 5 minutes, in the background, the app reads each process's running totals and adds what changed to its program. Because the totals keep counting between scans, a process that is running at two scans is counted exactly.

  • Kept by path, not pid: an app's helper processes add up under the app, and node keeps its history across Homebrew upgrades.
  • What 5-minute scans can't see is shown as Unseen, not hidden.
  • Hourly for 48 hours and daily for 90 days, in a file of a few MB.

# the menu's charts and top processes, live
$ ssh mac-mini
$ macmon-indicator

# once, for scripts
$ macmon-indicator --once --json

# process history over the last 7 days
$ macmon-indicator --once --history --range 7d

In a terminal, also over SSH

macmon-indicator gets its data from the app running on that Mac, so the numbers match the menu. The charts are drawn in braille dots and grow with the terminal.

  • Switch range, sort column and view from the keyboard; filter process history as you type.
  • --once prints and exits; --json is for scripts.
  • The two talk over a Unix socket that only your user can open.

Small enough to forget about

The sensors come from macmon, which needs no sudo. The app is AppKit only, draws its charts by hand, and redraws the menu bar only when a number has changed enough to matter.

  • History is one fixed-size file of about 248 KB. It never grows.
  • Process scanning for the menu runs only while the menu, the window or a terminal view is open.
  • Sampling slows to every 10 s while the displays sleep, and stops during system sleep.
  • An optional, read-only root mode adds disk use of system processes. Off by default.

Install

macmon is included in the app. After installing, open MacMon Indicator and turn on Settings → Launch at login.

Homebrew

The simplest way. It also puts macmon-indicator on your PATH, and there is no Gatekeeper prompt.

brew install --cask \
  vothanhdat/tap/macmon-indicator
Download

Get the zip from Releases and move the app to Applications. It isn't notarized, so clear the quarantine flag once:

xattr -dr com.apple.quarantine \
  "/Applications/MacMon Indicator.app"
From source

Needs the Xcode Command Line Tools and brew install macmon; Rust for the terminal view.

git clone https://github.com/\
vothanhdat/macmon-menubar.git
cd macmon-menubar && make install
